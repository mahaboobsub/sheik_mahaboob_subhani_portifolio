# Sheik Mahaboob Subhani — AI-SDE Portfolio

Apple-grade cinematic developer portfolio for **Sheik Mahaboob Subhani**, an AI-SDE specializing in RAG Pipelines, Knowledge Graphs, LangGraph Agents, Autonomous Multi-Agent Systems, FastAPI & Node.js.

Deployed on Vercel → *(add URL after deploy)*

## Tech Stack

- **Framework**: Next.js 15 (App Router), TypeScript strict
- **Styling**: Tailwind CSS v4
- **Animation**: Motion (motion/react), GSAP + ScrollTrigger
- **AI Chat**: Gemini 2.0 Flash via @google/genai, grounded in resume & case studies
- **UI**: cmdk (⌘K command palette), next-themes, lucide-react
- **Deploy**: Vercel

## Features

- **Pinned Scroll Storytelling** — Retrieve → Reason → Ship architecture showcase
- **5 Project Case Studies** — BloodBridge AI, AI Exam Generator, Fashion Recommender, Password Manager, NIT-AP Dashboard
- **Ask AI Assistant** — Gemini-powered chat with 4-stage agent pipeline visualization (Retrieving → Connecting → Processing → Verified)
- **6-Tile Skills Bento Grid** — Languages, AI & Data, Backend, Tools, OCI Certification, GitHub Activity
- **Experience Timeline** — Ruvinsys Global Solutions + NIT Andhra Pradesh
- **Contact Form** — Email copy, GitHub, LinkedIn, résumé download

## Getting Started

```bash
npm install
npm run dev
```

Create `.env.local`:
```
GEMINI_API_KEY=your_gemini_api_key
```

## Deploy on Vercel

1. Push to GitHub
2. Import repo on [vercel.com](https://vercel.com)
3. Add `GEMINI_API_KEY` environment variable
4. Deploy
